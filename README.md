# Database Bottleneck Simulation

This Python script simulates a database with a limited query processing capacity. It demonstrates how an application making too many requests can overwhelm the database, causing significant delays and illustrating a common performance bottleneck.

## Language

`python`

## How to Run

Save the code as `db_bottleneck.py` and run it from your terminal using `python db_bottleneck.py`.
